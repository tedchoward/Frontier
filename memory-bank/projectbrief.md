# Project Brief: Frontier/OPML Editor

## Overview

Frontier (also known as the OPML Editor) is an open-source project that serves as a high-performance web content management system, object database, system-level and internet scripting environment. It includes source code editing and debugging capabilities. The project was originally developed by UserLand Software, Inc. and is now maintained as an open-source project under the GNU General Public License v2.

## Core Objectives

- Provide a robust and high-performance web content management system
- Offer a flexible object database for storing and managing data
- Enable system-level scripting and automation
- Support internet scripting for web development and content management
- Include tools for source code editing and debugging
- Maintain cross-platform compatibility (macOS, Windows)

## Target Audience

- Web developers and content managers
- System administrators and power users
- Programmers and developers who need a robust scripting environment
- Organizations requiring custom content management solutions

## Key Features

- Object database system for structured data storage and retrieval
- Scripting environment with debugging capabilities
- Web content management tools and features
- Cross-platform compatibility (builds for macOS and Windows)
- Extensible architecture with SDK support
- Integration capabilities with MySQL and SQLite

## Development Status

The project is mature with multiple stable and development branches:
- Master branch: More stable builds (latest release: OPML Editor v10.1b21)
- Develop branch: More experimental builds (latest release: OPML Editor v10.2d4)

## Project Scope

The project includes:
1. Core Frontier/OPML Editor application
2. Supporting libraries and frameworks
3. SDK for extending functionality
4. Build configurations for multiple platforms and development environments

## Success Criteria

- Cross-platform compatibility maintained
- Performance and stability requirements met
- Backward compatibility with existing scripts and data
- Comprehensive documentation for users and developers
- Active community support and contribution

## Constraints

- Must maintain compatibility with various build environments (Xcode, Visual Studio, CodeWarrior, GNU tools)
- Must adhere to GPL v2 licensing requirements
- Must support both modern and legacy systems
